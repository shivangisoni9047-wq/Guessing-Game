# Number Guessing Game

A simple and interactive number guessing game built using HTML, CSS, and JavaScript.

## About the Project

In this game, the computer randomly selects a number between **0 and 10**, including both 0 and 10. The player has to guess the correct number.

The game provides feedback based on the player's guess and allows them to try again until they find the correct number.

## Features

- Random number generation between 0 and 10
- User-friendly interface
- Instant feedback on guesses
- Interactive gameplay
- Simple and clean design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Enter a number between **0 and 10**.
2. Submit your guess.
3. The game checks your guess against the randomly generated number.
4. Keep trying until you guess the correct number.

## Project Structure

- `index.html` - Structure of the game
- `style.css` - Styling and layout
- `app.js` - Game logic and functionality
